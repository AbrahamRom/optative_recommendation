# 🎓 University Elective Recommendation System

![NLP](https://img.shields.io/badge/NLP-spaCy%20%7C%20HuggingFace-green)
![Streamlit](https://img.shields.io/badge/UI-Streamlit-FF4B4B?logo=streamlit&logoColor=white)

This project is an intelligent system designed to recommend elective subjects to university students. It uses advanced **Natural Language Processing (NLP)** techniques, AI-generated tag extraction, and semantic embedding models to connect a student's profile and interests with their ideal courses.

---

## 🚀 Main Features and Workflow

The system operates using a 5-stage main pipeline:

1. **Preprocessing**: Cleaning and normalizing the descriptive texts of students and courses.
2. **Tag Extraction**: Keyword detection using `spaCy` and automatic suggestions generated by AI (LLM via OpenRouter/mistral-7b-instruct).
3. **Embedding Generation**: Transformation of tags into semantic vectors using pre-trained models such as `distiluse-base-multilingual-cased-v1`.
4. **Similarity Calculation**: Evaluation of the degree of compatibility (matching) between a student and a course using the **cosine similarity** metric.
5. **Recommendation Engine**: Generation of a personalized ranking showing the most relevant courses for each student.

---

## 📂 Project Structure

The repository is organized as follows:

- `data/`: Contains the course and student datasets, as well as the generated embeddings and tags.
- `src/`: Main source code (preprocessing logic, tag extraction, embeddings, and recommendation).
- `app/`: Interactive user interface developed in **Streamlit** for students and teachers.
- `documentation/`: Formal project documentation in LaTeX format.

## 🛠️ Getting Started (Installation)

Follow these steps to run the project on your local machine:

### 1. Clone the repository and prepare the environment
It is highly recommended to use a virtual environment to avoid dependency conflicts.

```bash
git clone https://github.com/AbrahamRom/optative_recommendation.git
cd optative_recommendation

# Create virtual environment (optional but recommended)
python -m venv venv
# Activate environment (Linux/macOS)
source venv/bin/activate
# Activate environment (Windows)
venv\Scripts\activate
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Configure environment variables
If you want to use AI-powered tag extraction, create a `.env` file in the root of the project and add your OpenRouter key:

```env
OPENROUTER_API_KEY=your-api-key-here
```

## 💻 Usage and Execution

You can use the project in two main ways:

### Run the Pipeline (Backend)
To process the data, extract tags, generate embeddings, and calculate recommendations via the console, run:
```bash
python src/run_workflow.py
```

### Run the Graphical Interface (Frontend)
To start the interactive web interface based on Streamlit:
```bash
streamlit run app/main.py
```
*(Make sure to point to the correct main file inside the `app/` folder if it has another name).*
